# ATLAS Store

متجر إلكتروني كامل بالعربي لملابس رجالي — دفع عند الاستلام، شحن اطلس بسعر موحّد، تسجيل دخول بكود على الإيميل، وإشعار إيميل بكل أوردر.

مبني بـ **Next.js 15 + TypeScript + Tailwind v4 + Supabase + Resend**.

# 2. Resend — عشان الأوردر يوصلك إيميل

من غير الخطوة دي **مش هتوصلك أوردرات لما ترفع الموقع**.

### 2.1 اعمل حساب

1. ادخل على <https://resend.com>
2. اضغط **Sign Up** وسجّل بإيميلك (`iaomn8406@gmail.com`)
3. أكّد إيميلك من الرسالة اللي هتوصلك

> الخطة المجانية بتديك **٣٠٠٠ إيميل في الشهر** — أكتر من كفاية.

### 2.2 اعمل مفتاح API

1. من القايمة الجنب اضغط **API Keys**
2. اضغط **Create API Key**
3. الاسم: `atlas-store` · الصلاحية: **Full access**
4. اضغط **Add**
5. **انسخ المفتاح دلوقتي حالًا** — بيبدأ بـ `re_` ومش هيظهرلك تاني بعد ما تقفل النافذة

### 2.3 حط المفتاح في المشروع

اعمل ملف اسمه `.env.local` في مجلد المشروع (نفس مكان `package.json`) واكتب فيه:

```bash
RESEND_API_KEY=re_ضع_المفتاح_هنا
ORDER_EMAIL_TO=iaomn8406@gmail.com
ORDER_EMAIL_FROM=ATLAS Store <onboarding@resend.dev>
```

> **`ORDER_EMAIL_FROM`:** سيبه `onboarding@resend.dev` — ده بيشتغل فورًا من غير أي إعدادات. لما تربط دومينك في Resend غيّره لـ `ATLAS Store <orders@yourdomain.com>` عشان الإيميل ما يروحش في الـ Spam.
>
> **أكتر من إيميل؟** `ORDER_EMAIL_TO=iaomn8406@gmail.com,another@gmail.com`

### 2.4 اللي هيوصلك في كل أوردر

| الجزء | التفاصيل |
|---|---|
| العميل | الاسم، رقمين موبايل، الإيميل |
| العنوان | المحافظة ← المركز/الحي ← القرية ← العنوان بالتفصيل ← علامة مميزة |
| المنتجات | كل منتج **باللون والمقاس المختارين** + الكمية + كود المورد (SKU) |
| الحساب | الإجمالي الفرعي + شحن اطلس + المطلوب تحصيله |
| أزرار | واتساب العميل · اتصال بالعميل — من جوه الإيميل |

نفس المنتج لو اتطلب بمقاسين مختلفين بيجي في **سطرين منفصلين**، عشان تعرف تطلبه من المورد صح.

# 3. Supabase — تسجيل الدخول

## ❓ إجابة سؤالك: حساب جديد ولا مشروع جديد؟

**الاتنين.** لو معندكش حساب Supabase خالص:

1. **اعمل حساب جديد** (مجاني، بتسجّل بحساب جوجل في ثانية)
2. **وبعدين اعمل مشروع جديد** جوه الحساب ده اسمه `atlas-store`

لو **عندك حساب Supabase بالفعل**: متعملش حساب جديد — ادخل عليه و**اعمل مشروع جديد بس**.

> **ليه مشروع لوحده؟** كل مشروع Supabase = قاعدة بيانات منفصلة. لو خلطت المتجر مع أي مشروع تاني هتلخبط في البيانات. المشروع المجاني بيسمح بمشروعين نشطين في الحساب.

## ❓ اللي هيحصل بالظبط

1. العميل يدوس **إتمام الطلب** → الموقع يحوّله لصفحة تسجيل الدخول
2. يكتب إيميله → يوصله **كود ٦ أرقام** على الجيميل
3. يكتب الكود → يرجع لصفحة إتمام الطلب **وبياناته متعبّية لوحدها**
4. لو عايز باسورد بدل الكود، فيه تبويب تاني — بس **برضو هيوصله كود تأكيد** أول مرة
5. لو سجّل خروج ورجع تاني، **بياناته كلها لسه موجودة** (اسم، تليفون، محافظة، مركز، قرية، عنوان)

## 3.1 اعمل الحساب والمشروع

1. ادخل على <https://supabase.com> واضغط **Start your project**
2. سجّل بحساب جوجل (أسرع حاجة)
3. اضغط **New Project**
4. املا البيانات:
   - **Name:** `atlas-store`
   - **Database Password:** اضغط **Generate a password** و**احفظه في مكان آمن**
   - **Region:** اختار `Central EU (Frankfurt)` — أقرب واحدة لمصر
5. اضغط **Create new project**
6. **استنى دقيقتين** لحد ما المشروع يجهز

## 3.2 اعمل جداول قاعدة البيانات

1. من القايمة الجنب اضغط **SQL Editor**
2. اضغط **New query**
3. افتح ملف **`supabase/schema.sql`** من مجلد المشروع عندك
4. **انسخ محتواه كله** والصقه في المربع
5. اضغط **Run** (أو `Ctrl + Enter`)
6. لازم تشوف **Success. No rows returned** في الأخضر

> ده بيعمل جدولين: `profiles` (بيانات العملاء) و `orders` (نسخة من الأوردرات)، وبيحمي كل عميل إنه يشوف بياناته هو بس.

## 3.3 ⚠️ خلّي الإيميل يبعت كود بدل لينك

**دي أهم خطوة وأكتر واحدة الناس بتنساها.** Supabase افتراضيًا بيبعت **لينك** — إحنا عايزين **كود ٦ أرقام**.

1. من القايمة الجنب: **Authentication**
2. اضغط **Emails** (أو **Email Templates**)
3. هتلاقي قدامك كذا قالب. لازم تعدّل **اتنين**:

### القالب الأول: `Magic Link`

امسح اللي مكتوب كله والصق ده:

```html
<h2>كود الدخول — ATLAS Store</h2>
<p>الكود بتاعك هو:</p>
<h1 style="letter-spacing:8px;font-family:monospace">{{ .Token }}</h1>
<p>الكود صالح لمدة ساعة واحدة.</p>
<p>لو مش انت اللي طلبته، تجاهل الرسالة دي.</p>
```

### القالب التاني: `Confirm signup`

امسح اللي مكتوب كله والصق ده:

```html
<h2>أكّد حسابك — ATLAS Store</h2>
<p>كود التأكيد بتاعك هو:</p>
<h1 style="letter-spacing:8px;font-family:monospace">{{ .Token }}</h1>
<p>الكود صالح لمدة ساعة واحدة.</p>
```

4. اضغط **Save** على كل قالب

> **المهم:** `{{ .Token }}` هو اللي بيطلع الكود. لو سبت `{{ .ConfirmationURL }}` هيبعت لينك والكود مش هيشتغل.

## 3.4 اسمح بإنشاء حسابات جديدة

1. **Authentication** → **Sign In / Providers**
2. اتأكد إن **Email** مفعّل (Enabled)
3. اتأكد إن **Allow new users to sign up** مفتوح
4. **Confirm email** خليه مفتوح (ده اللي بيخلي الكود يتبعت)

## 3.5 خد مفاتيح المشروع

1. **Project Settings** (الترس تحت) → **Data API**
2. انسخ الاتنين دول:
   - **Project URL** — شكله `https://abcdefgh.supabase.co`
   - **anon public** key — نص طويل بيبدأ بـ `eyJ`

3. ضيفهم في ملف `.env.local` تحت اللي كتبته قبل كده:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://ضع_الرابط_هنا.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ_ضع_المفتاح_الطويل_هنا
```

> **مفيش خطر:** المفتاح ده اسمه `anon public` يعني معمول عشان يبقى في المتصفح. الحماية الحقيقية في سياسات RLS اللي عملناها في الخطوة 3.2.

## 3.6 جرّب على جهازك

**اقفل السيرفر** (`Ctrl + C` في التيرمنال) و**شغّله تاني** — لازم يعيد التشغيل عشان يقرا المتغيرات الجديدة:

```bash
npm run dev
```

جرّب كده:
1. ضيف منتج للسلة → اضغط **إتمام الطلب**
2. المفروض يحوّلك لصفحة تسجيل الدخول
3. اكتب إيميلك → اضغط **ابعتلي الكود**
4. افتح جيميلك → هتلاقي كود ٦ أرقام (**لو مش لاقيه شوف Spam و Promotions**)
5. اكتب الكود → المفروض يرجّعك لصفحة إتمام الطلب

# 4. الرفع على Vercel

## 4.1 المشروع على GitHub

المشروع مرفوع بالفعل على: <https://github.com/Mohamedre123/atlasstore>

لو عملت أي تعديل وعايز ترفعه:

```bash
git add -A
```

```bash
git commit -m "تعديلات جديدة"
```

```bash
git push
```

## 4.2 اربط Vercel

1. ادخل على <https://vercel.com> واضغط **Sign Up**
2. اختار **Continue with GitHub** (مهم — عشان يشوف الريبو)
3. اضغط **Add New** → **Project**
4. هتلاقي `atlasstore` في القايمة → اضغط **Import**
5. **متغيّرش أي إعدادات** — Vercel بيعرف Next.js لوحده

## 4.3 ⚠️ حط المتغيرات قبل ما تضغط Deploy

في نفس الصفحة اضغط على **Environment Variables** وضيف **٥ متغيرات** واحد واحد:

| الاسم (Key) | القيمة (Value) |
|---|---|
| `RESEND_API_KEY` | المفتاح بتاع Resend |
| `ORDER_EMAIL_TO` | `iaomn8406@gmail.com` |
| `ORDER_EMAIL_FROM` | `ATLAS Store <onboarding@resend.dev>` |
| `NEXT_PUBLIC_SUPABASE_URL` | رابط مشروع Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | مفتاح anon public |

> **نسخ ولصق من `.env.local` بالظبط** — أي حرف ناقص والموقع مش هيشتغل.

بعدين اضغط **Deploy** واستنى دقيقتين.

## 4.4 ⚠️ رجّع لـ Supabase وقوله الدومين

بعد ما الرفع يخلص Vercel هيديك لينك شكله `https://atlasstore-xxxx.vercel.app`. **انسخه.**

1. ارجع لـ Supabase → **Authentication** → **URL Configuration**
2. **Site URL:** حط لينك الموقع
3. **Redirect URLs:** اضغط **Add URL** وحط:
   ```
   https://لينك-موقعك.vercel.app/**
   ```
4. اضغط **Save**

> **من غير الخطوة دي تسجيل الدخول هيفشل على الموقع المرفوع** حتى لو شغال على جهازك.

# 🎨 إزاي أعدّل حاجة؟

## أغيّر سعر الشحن

`data/locations.ts` — أول ٣ سطور:

```ts
export const SHIPPING_FLAT_RATE = 80        // السعر بالجنيه
export const SHIPPING_METHOD_NAME = 'شحن اطلس'
export const DELIVERY_WINDOW = '٢ - ٥ أيام عمل'
```

السعر موحّد لكل مصر، ومفيش شحن مجاني. سعر الشحن بيفضل فاضي في الملخص («حدد عنوانك») لحد ما العميل يختار المحافظة.

## أضيف مركز أو حي ناقص

نفس الملف — دوّر على المحافظة وضيف الاسم في `areas`:

```ts

  name: 'الدقهلية',
  areas: ['المنصورة', 'طلخا', 'المركز الجديد هنا'],
},
```

## أضيف منتج جديد

`data/products.ts` — انسخ منتج موجود وغيّر بياناته:

```ts
{
  id: 'atl-new',                     // لازم يكون فريد ومتغيّروش بعدين
  slug: 'new-product',               // الرابط: /product/new-product
  name: 'اسم المنتج',
  shortDescription: 'وصف سطر واحد',
  description: 'الوصف الكامل — كل سطر بيبقى فقرة',
  price: 550,
  compareAtPrice: 700,               // السعر قبل الخصم (اختياري)
  images: ['/img/new-1.webp'],       // حط الصور في public/img
  category: 'tshirts',               // tshirts أو sets أو abayas
  variants: [
    { name: 'اللون', options: ['اسود', 'أبيض'] },
    { name: 'المقاس', options: ['M', 'L', 'XL'] },
  ],
  inStock: true,
  featured: true,
  sku: 'ATL-NEW',                    // كود المورد — بيوصلك في الإيميل
}
```

> **مهم:** أي متغير تكتبه هنا لازم العميل يختار منه، والاختيار بيوصلك في الإيميل. لو منتج مالوش مقاسات، امسح سطر المقاس خالص.

# 🧩 الأنيميشن — إزاي بيشتغل

## الظهور عند التمرير (`components/ui/reveal.tsx`)

مراقب واحد للصفحة كلها. أي عنصر عليه `data-reveal` بياخد كلاس `in` أول ما يدخل الشاشة، والـ CSS بيتولى الباقي.

الأنواع: `data-reveal=""` (طلوع وتلاشي) · `side` · `zoom` · `mask` (كشف سطر من تحت) · `line` (خط بيتمد).

> **تحذير:** ماتحطش قص (`clip-path`) ولا `scaleX(0)` على العنصر اللي عليه `data-reveal` نفسه — مساحته بتبقى صفر و IntersectionObserver مابيحسبهوش داخل الشاشة، فالحركة عمرها ما بتشتغل. الحركة بتتحط على عنصر جوّه أو بقناع.

## زرار «أضف للسلة» (`components/product/add-to-cart-button.tsx`)

موجة كحلي بتملى الزرار من تحت لفوق، وقطعة بتطير جوه الشنطة، وبعدها الزرار بيقول «اتضاف للسلة».

الزرار **مربوط بالنتيجة الحقيقية**: `onAction` بيرجع `false` لو العميل ما اختارش المقاس، والحركة بترجع لمكانها ومش بتكمّل. درج السلة بيتفتح في `onDone` بعد ما الحركة تخلص، مش في نصّها.

## زرار تأكيد الطلب (`components/checkout/send-button.tsx`)

تلات حالات: `idle` → `busy` (قوس بيلف وخط توصيل بيتملي تحت) → `done` (علامة صح). لو السيرفر رجّع خطأ، الزرار بيرجع `idle` والعميل يقدر يجرّب تاني أو يبعت الأوردر واتساب.

## مشهد صفحة الدخول (`components/auth/auth-scene.tsx`)

علامة أطلس عايمة في الماء: حلقات موج بتتوسّع منها، هالة بتتنفّس، والعلامة بتميل ناحية الماوس. الفورم ظاهر من أول لحظة — مفيش أي حاجة بتتقفل ورا تفاعل.

> **اللي مقفّل الحركة في جهازه** (Reduced Motion) بيشوف الموقع كامل شغال ١٠٠٪ من غير أي حركة.

# 🆘 مشاكل شائعة

### «الأوردر مش بيوصلني إيميل»
- اتأكد إن `RESEND_API_KEY` متحطّ **في Vercel** مش بس على جهازك
- شوف Spam في الجيميل
- Resend → **Logs** هيوريك الإيميل اتبعت ولا لأ

### «الكود مش بيوصل على الإيميل»
- **٩٠٪ من الحالات:** قوالب الإيميل في Supabase لسه فيها لينك بدل `{{ .Token }}` — راجع [خطوة 3.3](#33-️-خلي-الإيميل-يبعت-كود-بدل-لينك)
- شوف Spam و Promotions
- Supabase مجانًا بيبعت عدد محدود من الإيميلات في الساعة. لو بتجرّب كتير هتتقفل مؤقتًا — استنى شوية

### «تسجيل الدخول شغال على جهازي وواقف على الموقع»
- نسيت [خطوة 4.4](#44-️-رجع-لـ-supabase-وقوله-الدومين) — لازم تحط لينك الموقع في Supabase → URL Configuration

### «الموقع مش بيشتغل بعد الرفع»
- Vercel → **Deployments** → افتح آخر واحد → **Build Logs** واقرا الخطأ
- أغلب الأخطاء = متغير بيئة ناقص أو فيه مسافة زيادة

### «عايز أقفل تسجيل الدخول مؤقتًا»
امسح `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` من Vercel واعمل Redeploy. المتجر هيشتغل عادي والعميل هيطلب من غير تسجيل.

# 🔒 الأمان

- **الأسعار بتتحسب من السيرفر مش من المتصفح** — لو حد عدّل السعر في المتصفح، السيرفر بيتجاهله وبيحسب من `data/products.ts`
- **المتغيرات إجبارية** — أوردر من غير مقاس أو بلون مش موجود بيترفض
- **المركز لازم يكون تابع للمحافظة** المختارة
- **RLS مفعّل** على كل جداول Supabase — كل عميل يشوف بياناته هو بس
- **مافيش بيانات بنكية** خالص — الدفع كله عند الاستلام
- أرقام الموبايل لازم تكون مصرية صحيحة (`010` / `011` / `012` / `015`)
