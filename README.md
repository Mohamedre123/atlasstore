# ATLAS Store

متجر إلكتروني كامل بالعربي (RTL) لملابس رجالي — دفع عند الاستلام، شحن اطلس بسعر موحّد، وإشعار إيميل بكل أوردر.

مبني بـ **Next.js 15 + TypeScript + Tailwind v4**.

---

## تشغيل سريع

```bash
npm install
npm run dev
```

افتح <http://localhost:3000>

> من غير مفتاح Resend، الأوردر بيتطبع في التيرمنال بدل ما يتبعت بالإيميل — ده مقصود عشان تقدر تجرّب المتجر محليًا.

---

## ١. إشعار الأوردر بالإيميل

من غير الخطوة دي **مش هتوصلك أوردرات على السيرفر**.

1. اعمل حساب مجاني على [resend.com](https://resend.com) — ٣٠٠٠ إيميل شهريًا مجانًا.
2. من `API Keys` اعمل مفتاح جديد وانسخه.
3. اعمل ملف `.env.local` في جذر المشروع:

```bash
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxx
ORDER_EMAIL_TO=iaomn8406@gmail.com
ORDER_EMAIL_FROM=ATLAS Store <onboarding@resend.dev>
```

**اللي بيوصلك في كل إيميل أوردر:**

| البيانات | التفاصيل |
|---|---|
| العميل | الاسم، رقمين موبايل، الإيميل |
| العنوان | المحافظة ← المركز/الحي ← القرية/المنطقة ← العنوان بالتفصيل ← علامة مميزة |
| المنتجات | كل منتج **باللون والمقاس المختارين**، الكمية، وكود المورد (SKU) |
| الحساب | الإجمالي الفرعي + شحن اطلس + الإجمالي المطلوب تحصيله |
| أزرار سريعة | واتساب العميل · اتصال بالعميل — من جوه الإيميل |

العميل كمان بيوصله إيميل تأكيد لو كتب إيميله.

## ٢. الرفع على Vercel

1. ارفع المشروع على GitHub.
2. من [vercel.com](https://vercel.com) اضغط **Add New → Project** واختار الريبو.
3. في **Environment Variables** ضيف المتغيرات الثلاثة اللي فوق.
4. **Deploy**.

بعد الرفع تقدر تربط دومينك من `Settings → Domains`.

> لو نسيت متغيرات البيئة، الموقع هيشتغل عادي بس الأوردر مش هيتبعت والعميل هيشوف رسالة تقوله يكلّمك واتساب.

## ٣. الشحن

كل إعدادات الشحن في ملف واحد: **`data/locations.ts`**

```ts
export const SHIPPING_FLAT_RATE = 80        // سعر الشحن بالجنيه
export const SHIPPING_METHOD_NAME = 'شحن اطلس'
export const DELIVERY_WINDOW = '٢ - ٥ أيام عمل'
```

- السعر **موحّد لكل محافظات مصر** — مفيش أسعار مختلفة ومفيش شحن مجاني.
- سعر الشحن **بيفضل فاضي** في ملخص الطلب («حدد عنوانك») لحد ما العميل يختار المحافظة، وبعدين بيظهر ٨٠ ويتضاف للإجمالي.
- مفيش شركات شحن — التوصيل بمندوبك.

في نفس الملف كمان **٢٧ محافظة بمراكزها وأحيائها** (أكتر من ٤٠٠ مركز). عشان تضيف مركز، ضيفه في مصفوفة `areas` بتاعة المحافظة.

## ٤. المنتجات

كل المنتجات في ملف واحد: **`data/products.ts`**، وصورهم في `public/img/`.

```ts
{
  id: 'atl-oncloud',                 // معرّف ثابت — ما تغيّروش بعد ما يبدأ البيع
  slug: 'on-cloud-tracksuit',        // الرابط: /product/on-cloud-tracksuit
  name: 'ترينج رجالي من On Cloud',
  shortDescription: 'وصف سطر واحد',
  description: 'الوصف الكامل — كل سطر بيبقى فقرة',
  price: 650,
  compareAtPrice: 800,               // اختياري — بيظهر مشطوب وبيتحسب الخصم
  images: ['/img/oncloud-1.webp'],   // أول صورة هي الرئيسية
  category: 'sets',                  // slug من مصفوفة categories
  variants: [
    { name: 'اللون', options: ['اسود', 'أبيض', 'كحلي'] },
    { name: 'المقاس', options: ['M', 'L', 'XL'] },
  ],
  inStock: true,
  featured: true,
  badge: 'طقم كامل',                 // شارة على الصورة
  sku: 'ATL-ONCLOUD',                // بيتبعت في إيميل الأوردر عشان تطلبه من المورد
}
```

**المتغيرات:** العميل لازم يختار من كل مجموعة قبل ما يضيف للسلة، والاختيار بيتسجّل في السلة وبيوصلك في الإيميل. لو نفس المنتج اتطلب بمقاسين مختلفين، بيظهر سطرين منفصلين في الأوردر.

**إضافة صور:** حط الصور في `public/img/` واكتب مسارها `/img/اسم-الملف.webp`. تقدر كمان تحط لينكات صور خارجية — `next.config.mjs` بيسمح بأي دومين.

## ٥. الهوية والبانر

**`data/site.ts`**

| الحاجة | الحقل |
|---|---|
| اللوجو | `logo` — الملف في `public/img/logo.webp` |
| البانر الرئيسي | `hero.image` + `hero.imageWidth/imageHeight` |
| نص وزرار البانر | `hero.title` · `hero.subtitle` · `hero.cta` |
| رقم الواتساب | `contact.whatsapp` — بصيغة دولية بدون `+` |
| أرقام التليفون والإيميل | `contact` |
| لينكات السوشيال | `social` — سيبها فاضية عشان تختفي |
| شريط الإعلان المتحرك | `ticker` |

**البانر:** بيتعرض بنسبته الأصلية `1800×563` كاملة على الديسكتوب. على الفون بنقص الأطراف الزرقا الفاضية بس (`aspect-[16/10]`) عشان الموديل يبان بحجم مناسب بدل شريط رفيع. لو غيّرت البانر، حدّث `imageWidth/imageHeight` بمقاس صورتك.

## عرض المنتجات

- **الفون:** كاروسيل صف واحد بالسحب يمين/شمال، مع إظهار طرف الكارت التالي عشان يبان إنه بيتحرك.
- **الديسكتوب:** جريد ٣ أو ٤ أعمدة.
- **صفحة المتجر والأقسام:** جريد عمودين على الفون عشان تقدر تتصفّح وتفلتر كل المنتجات مرة واحدة.

كله CSS خالص من غير مكتبات كاروسيل، فبيشتغل فورًا ومابيتقّلش الصفحة.

---

## ملاحظات أمان

- **الأسعار بتتحسب من السيرفر مش من المتصفح.** لو حد عدّل السعر في المتصفح، السيرفر بيتجاهله وبيحسب من `data/products.ts`.
- **المتغيرات إجبارية ومتحقَّق منها.** أي مقاس أو لون مش موجود في تعريف المنتج بيترفض الأوردر.
- **المركز لازم يكون تابع للمحافظة** المختارة، وإلا الأوردر بيترفض.
- أرقام الموبايل لازم تكون مصرية صحيحة (`010` / `011` / `012` / `015`).
