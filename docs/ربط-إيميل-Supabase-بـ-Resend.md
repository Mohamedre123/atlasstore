# ربط إيميل Supabase بـ Resend

## المشكلة

لما العميل يطلب كود دخول، Supabase بيرجّع:

```
500 — "Error sending confirmation email"
```

## السبب

Supabase بيبعت الإيميلات بسيرفر مجاني **مشترك بين كل المشاريع**، وحدّه:

- **٢ لـ ٤ رسايل في الساعة بس**
- بيقع كتير ومش مضمون
- Supabase نفسها بتقول إنه **للتجربة بس مش للاستخدام الحقيقي**

عشان كده كان شغال أول مرة وبعدين وقف — استهلكت الحد.

## الحل

نخلي Supabase يبعت عن طريق **Resend** بتاعك. عندك دومين موثّق عندهم أصلاً، يعني:

- **٣٠٠٠ رسالة في الشهر** بدل ٤ في الساعة
- بتوصل في الوارد مش السبام (دومينك موثّق)
- نفس الحساب اللي بيبعت إيميلات الأوردرات

---

## الخطوات

### 1. اعمل مفتاح SMTP في Resend

1. ادخل <https://resend.com/api-keys>
2. اضغط **Create API Key**
3. الاسم: `supabase-smtp` · الصلاحية: **Sending access**
4. **انسخ المفتاح فورًا** (بيبدأ بـ `re_`) — مش هيظهر تاني

> تقدر تستخدم نفس المفتاح الموجود، بس مفتاح منفصل أنضف — لو حصلت مشكلة في واحد ما تأثرش على التاني.

### 2. فعّل SMTP في Supabase

1. ادخل مشروعك على <https://supabase.com/dashboard>
2. **Project Settings** (الترس تحت الشمال)
3. اضغط **Authentication** من القايمة
4. انزل لقسم **SMTP Settings**
5. فعّل **Enable Custom SMTP**

املا الخانات كده بالظبط:

| الخانة | القيمة |
|---|---|
| **Sender email** | `info@atlass-clothes.store` |
| **Sender name** | `ATLASs Store` |
| **Host** | `smtp.resend.com` |
| **Port number** | `465` |
| **Username** | `resend` |
| **Password** | مفتاح Resend اللي نسخته (`re_...`) |

> ⚠️ **الـ Username حرفيًا كلمة `resend`** — مش إيميلك ولا اسم حسابك. دي مش غلطة.

6. اضغط **Save**

### 3. ارفع حد الإرسال

في نفس الصفحة، انزل لـ **Rate Limits**:

- **Rate limit for sending emails**: غيّره من `4` لـ `100` (في الساعة)

الحد ده كان موضوع عشان السيرفر المجاني. دلوقتي بتبعت من حسابك فمالوش لازمة.

اضغط **Save**.

### 4. جرّب

1. افتح <https://atlass-clothes.store/login>
2. اسحب الحبل → اكتب إيميلك → **ابعتلي الكود**
3. المفروض الكود يوصل في ثواني

لو ظهرت رسالة خطأ، **تحتها هتلاقي السبب التقني بخط صغير** — ابعتهولي.

---

## للتأكد إن كل حاجة تمام

في Resend → <https://resend.com/emails> هتلاقي كل الرسايل اللي اتبعتت، ومنها رسايل أكواد الدخول. لو الرسالة ظهرت هناك يبقى Supabase بيبعت صح.

## ملاحظة مهمة

قوالب الإيميل اللي ظبطناها قبل كده (Magic Link و Confirm signup) **هتفضل شغالة زي ما هي** — إحنا غيّرنا طريقة الإرسال بس، مش شكل الرسالة.
